# 基础概念

> 路径：AI Agent
>
> https://app.notion.com/p/3d1776baec49817a9f4ee373fe7becf5?pvs=204

Agent 学习中最基础的一层：先弄清楚 **模型本身、模型看到的信息、模型能调用的外部能力** 三者之间的边界。
## 🧭 这一层在 Agent 里的位置
基础概念不是 Agent 的“零件清单”，而是在回答一个更根本的问题：**为什么单独一个 LLM 还不能直接成为一个 Agent？**
可以先沿着这条关系理解：
`LLM → Prompt / Context → Tool → Tool Calling → Tool Runtime → Agent`
其中每一步都在解决一个不同的限制：
- **LLM**：负责理解、推理和生成，但本身只是模型。
- **Prompt / Context**：决定模型这一次能看到什么信息。
- **Tool**：把模型本身没有的外部能力提供给它，例如搜索、数据库、计算或调用 API。
- **Tool Calling**：让模型能够表达“我现在需要调用哪个工具、传什么参数”。
- **Tool Runtime**：真正执行工具，并把结果返回给模型。
- **Agent**：把这些能力组织成持续的“观察 → 判断 → 行动 → 获取结果”的系统。
所以：**Tool Calling 不是 Tool Runtime，模型也不是 Agent。** 前者负责提出调用请求，后者负责实际执行；Agent 则把模型、工具和循环组织起来。
## 计划收录
- LLM
- Prompt
- Context
- Token
- Tool
- Tool Calling
- Tool Runtime
- Agent
## 🔍 学习这些概念时要问
1. 这个东西是谁产生的？
2. 它里面装了什么信息？
3. 它解决了上一个节点的什么限制？
4. 它产生的结果又交给谁？
核心问题：**模型本身有什么能力？它能看到什么？它怎样获得外部能力？**
